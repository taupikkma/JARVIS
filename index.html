      Native System-Wide Overlay

      Aplikasi web ini sudah terhubung dengan jembatan window.JarvisAndroidBridge. Saat dibungkus ke APK Android (Capacitor / Android WebView), komponen berikut menjaga popup tetap hidup di luar aplikasi:

      1. AndroidManifest.xml Permissions

      <uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_SPECIAL_USE"/>

      2. Kotlin FloatingOverlayService.kt (WindowManager)

      val params = WindowManager.LayoutParams(
  WRAP_CONTENT, WRAP_CONTENT,
  WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY,
  FLAG_NOT_FOCUSABLE, PixelFormat.TRANSLUCENT
)
// START_STICKY menjaga bola mengambang tetap hidup meski app ditutup
